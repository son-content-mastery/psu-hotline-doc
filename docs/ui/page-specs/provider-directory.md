# Optional provider directory

- Route: `/providers`
- Authentication: public
- Main task: compare service categories and reference price ranges without implying government endorsement.

Place the localized non-endorsement warning before filters and results. Each card shows provider name, source status, service tags, nullable reference range/note, and an external contact link. `DEMO_ONLY` must explicitly say the listing is fictional. Never use “approved”, “certified”, ranking, reviews, paid placement, or a quality score until governance and verification policy are approved.

Filtering submits one allowlisted service code to the backend. Empty/error/loading states are text-readable, external links use `noopener noreferrer`, and prices are formatted by locale while remaining clearly labelled as reference values.
